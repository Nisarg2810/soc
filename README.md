# Shree Ohm Creation — website

Static website for Shree Ohm Creation (SOC Interiors), interior designers in Ahmedabad.
Live at **https://nisarg2810.github.io/soc/** once GitHub Pages is enabled.

## Edit and rebuild

All pages are generated by one script. Do not edit the HTML files by hand.

- Business details (phone, address, hours, numbers): `tools/config.py`
- Projects, services, FAQs and journal articles: `tools/content.py`
- Page layouts: `tools/build.py`
- Styles: `assets/css/site.css`, scripts: `assets/js/site.js`

```bash
python3 tools/build.py
```

Then commit and push. GitHub Pages updates within a minute or two.

See `DUMMY-CONTENT.md` for everything that is still a placeholder.

## Pages

Home, Projects (6 project pages), Services (6 service pages), Studio, Journal (4 articles), Contact, 404.

## SEO built in

- One clear H1 per page, keyword-led titles under 60 characters and descriptions under 160
- Canonical URLs, Open Graph and Twitter cards with a share image
- Structured data (JSON-LD): local business with address, geo, hours and services; WebSite; breadcrumbs; FAQ; Service; BlogPosting; CreativeWork for projects
- `sitemap.xml`, `robots.txt`, web manifest, favicons
- Fast: static HTML, no frameworks, responsive images with `srcset`, lazy loading, font `display=swap`
- Local signals: geo meta tags, areas served, Ahmedabad-focused service pages and articles

## After going live (this is where traffic actually comes from)

1. **Google Search Console**: add the property `https://nisarg2810.github.io/soc/`, verify, and submit `sitemap.xml`.
2. **Google Business Profile**: create or claim it, use the same name, address and phone as the site, link to the site, and add real photos. This matters most for "interior designer near me" searches.
3. **Real photos and projects**: replace the stock images. Original photos rank in Google Images; stock photos do not.
4. **Reviews**: ask happy clients to leave Google reviews.
5. **Listings**: keep the same name, address and phone on IndiaMART, Justdial, Houzz and Instagram, and link back to the site.
6. **Keep writing**: one useful article a month (costs, materials, design ideas for Ahmedabad homes).
7. **Custom domain**: `shreeohmcreation.com` (or `.in`) ranks and looks better than a github.io subfolder. Set it in GitHub Pages settings, then change `SITE_URL` and `BASE` in `tools/config.py` and rebuild.
